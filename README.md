# Агент в продакшене — репозиторий курса

Шаблон курса «Агент в продакшене: оценка, трейсы, опасные действия, деплой,
метрики» школы AI Sprints. Из него вы создаёте свой репозиторий и за 32
урока доводите в нём агента компании «Полярис-Снаб» до сервиса, который
работает без вас: отвечает по документам, действует в CRM, пишет трейсы,
спрашивает человека перед опасным действием, выкладывается и меряет себя.

## Как начать

1. Нажмите **Use this template** → **Create a new repository**, владелец —
   ваш аккаунт, видимость — **Public**: ИИ-ментор читает только публичные
   pull request.
2. Клонируйте свой репозиторий и откройте его в агентном редакторе.
3. Скопируйте `.env.example` в `.env` и заполните значения по уроку 1.
   Файл `.env` в git не попадает.
4. Дальше — по уроку 1: окружение Python 3.12 в `.venv`, данные компании в
   `data/`, первая проверка окружения.

Сервис запускается из корня репозитория, с урока 3:

```bash
uvicorn agent.app.main:app
```

Корень проекта Vercel в уроке 25 — тоже корень репозитория; точку входа
вы объявите в `pyproject.toml`, который появится в том же уроке.

## Структура

| Путь | Что здесь |
|---|---|
| `agent/` | сервис агента на FastAPI — появляется с урока 1 |
| `agent/prompts/rules.md` | правила ответа, которые дал заказчик; меняются только по уроку |
| `data/` | материалы компании из раздела «Ресурсы» урока 1; в git не коммитятся |
| `eval/` | набор вопросов, прогоны, метрики и пороги |
| `reports/` | отчёты уроков `apNN-*.md` и `apNN-*.txt` |
| `.github/workflows/pr-check.yml` | проверка pull request: размер, секреты, лишние файлы |

## Как сдавать

На каждый урок — ветка `ap-NN` от свежего `main` (`ap-01`, `ap-15`) и pull
request в `main` своего репозитория. Заголовок начинается с кода задачи
`AP-<урок>-1` без ведущего нуля: `AP-15-1 Структурированный лог`. В pull
request — файлы только этого урока и его отчёт в `reports/`, не больше 30
файлов. Ссылку на pull request сдаёте в задаче урока на платформе.

Работу проверяет ИИ-ментор Порфирий Петрович по критериям приёмки задания.
После приёмки влейте pull request в `main` сами: следующие уроки собирают
сервис оттуда. С вопросом по заданию — к ИИ-ментору в задаче; ментор-человек
— в чате на платформе.

## Требования

- Python 3.12, Git, аккаунт GitHub, любой агентный редактор.
- Ключ API WorkAI и пополненный API-счёт: шлюз `https://api.workai.su/v1`.
- Бесплатные тарифы: Neon, Langfuse Hobby, Docker Personal, Vercel Hobby —
  по урокам, где они нужны.
