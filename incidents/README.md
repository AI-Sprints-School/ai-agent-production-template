# Сборка агента к уроку 17

Небольшой агент «Полярис-Снаб» из тех же слоёв, что ваш сервис: поиск по
базе знаний, сборка контекста, вызов модели через шлюз WorkAI, инструмент
справочника контрагентов. Каждый запрос пишет трейс в
`incidents/traces/<request_id>.jsonl`. Ваш сервис в `agent/` эта сборка не
трогает и сама его не импортирует.

Устроена сборка проще вашего сервиса, и трейс у неё выглядит иначе:

| | Ваш сервис | Сборка |
|---|---|---|
| поиск | инструмент `search_docs`: модель решает, искать ли | всегда, до первого вызова модели |
| что дошло до модели | результат `search_docs` после порога `MIN_SIMILARITY` | отдельный шаг, спан `context`: `chunks_found` и `chunks_used` |
| поиск по чему | эмбеддинги в Neon, `similarity` от 0 до 1 | по словам, `score` — число общих слов с вопросом |
| начало дерева | `generation #1` → `tool:search_docs` | `search` → `context` → `generation #1` |

Приём разбора урока 17 от этого не меняется: от ответа назад по дереву к
первому спану с неверным выходом.

## Как запустить

Из корня репозитория, в `.venv` проекта:

```bash
pip install -r incidents/requirements.txt
python -m incidents.ask "Ваш вопрос"
python -m incidents.export_trace <request_id>
python -m incidents.export_trace <request_id> --only search,context
python -m incidents.check   # проверка сборки: 6 вопросов, на которые она отвечает верно
```

Адрес шлюза, модель и ключ сборка берёт из `.env` в корне репозитория:
`LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`. Поиск идёт по словам, без
эмбеддингов, поэтому платите вы только за вызовы модели — несколько вызовов
на вопрос.

Сервисом, если нужен адрес: `uvicorn incidents.app.main:app --port 8017`,
запрос `POST /ask` с телом `{"question": "…"}`.

## Что внутри

| Файл | Что делает |
|---|---|
| `app/config.py` | настройки: окружение, лимиты поиска, контекста и шагов |
| `app/kb.py` | фрагменты базы: строки прайсов и пункты регламентов из `fixtures/` |
| `app/search.py` | поиск по словам |
| `app/tools.py` | инструмент `find_counterparty` и его описание для модели |
| `app/loop.py` | агентный цикл и спаны |
| `app/trace.py` | запись спанов в файл трейса |
| `export_trace.py` | дерево спанов текстом; `--only` — корень и спаны по началу имени |
| `check.py` | проверка сборки: шесть вопросов с ожидаемыми словами в ответе |

Папка `traces/` в `.gitignore`: выгрузки трейсов идут в отчёт урока, а не
файлами в pull request.
